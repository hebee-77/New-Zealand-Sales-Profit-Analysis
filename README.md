# New Zealand Sales & Profit Analysis (SQL Server + Power BI)

## Overview
A complete end-to-end analytics project using SQL Server for data processing and Power BI for dashboard visualization.

## Objectives
- Analyze revenue, profit, margins by region and category.
- Identify top-performing and under-performing products.
- Study monthly sales trends and seasonal patterns.
- Provide insights to support decision-making.

## Dataset
- File: New_Zealand_Sales_and_Profit_Dataset.csv
- Records: 499
- Fields: Order_ID, Product, Category, Region, Sales, Profit, Order_Date

## Tech Stack
- SQL Server
- Power BI
- CSV / Excel
- GitHub
